CASE STUDY 01

AWS Monitoring & Logs

Architecture

Exporters feed Prometheus; Alloy sends logs to Loki. Grafana displays both, while Prometheus routes alerts through Alertmanager.

VERIFIED SCOPE

Apps / Hosts

Exporters / Alloy

Prometheus / Loki

Grafana
+

Alertmanager
Infrastructure

Terraform provisions the VPC, ALB and four EC2 servers: two Docker app hosts, a dedicated MySQL server and a monitoring server.

Metrics

Prometheus collects host, Docker, backend and MySQL metrics through Node Exporter, cAdvisor, /metrics and mysqld_exporter. Blackbox probes the ALB.

Logs

Grafana Alloy forwards app-container logs, MySQL journal logs and monitoring-service logs to Loki. Log ingestion was verified from all four servers.

Alerting

Prometheus evaluates host, backend, application and MySQL alerts. Alertmanager sends email; controlled tests confirmed firing and resolved notifications.

Access / RBAC

Grafana folders separate application, infrastructure and database dashboards. Developers, Operations and QA use team-based View, Edit and Admin permissions.

Automation / Verification

The final Terraform plan showed no drift. The integrated Ansible playbook reported changed=0 and failed=0 on all four servers; 11/11 targets were healthy.

CASE STUDY 02

3-Tier AWS & CI/CD

Architecture

Delivery targets the backend Auto Scaling environment. The ALB routes frontend and API traffic; the backend connects to private RDS MySQL.

VERIFIED SCOPE

GitHub

CodePipeline

CodeBuild

CodeDeploy

EC2 Auto Scaling
Architecture

A custom VPC spans two Availability Zones. An internet-facing ALB fronts private frontend/backend tiers and private RDS MySQL. The lab uses Single-AZ RDS.

CI/CD

GitHub changes enter CodePipeline. CodeBuild runs npm ci and backend tests, then packages the backend, AppSpec and scripts for CodeDeploy.

Networking

ALB path rules separate frontend and API traffic. App instances have no public IPs; security-group references restrict access between the ALB, backend and database.

Security

The backend retrieves database credentials from SSM Parameter Store at startup. The password uses SecureString, and EC2 uses IAM roles instead of static AWS credentials.

Monitoring

CloudWatch tracks EC2, Auto Scaling, ALB and RDS health. CPU alarms drive backend scaling; operational alarms send email through SNS.

Deployment Controls

CodeDeploy Blue/Green validates the replacement before traffic cutover. AppSpec ValidateService checks backend health and a database-backed API; new ASG instances receive the latest revision.

Repository README Portfolio lab with validated scaling and deployment workflows.
